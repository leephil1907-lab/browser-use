BROWSER USE

Agent execution

The UI submits an objective to /api/agent/run. The server owns credentials, browser sessions and action selection. The client never invents browser actions.

POST /api/agent/run
{
  "task": "…",
  "browser": "local | cloud",
  "model": "…",
  "startingUrl": "…"
}
DECISION RADAR

Discovery source

Radar data is requested from /api/decision/projects. Empty or unavailable responses stay empty; this interface contains no fallback catalogue.

GET /api/decision/projects
?q=…&category=…&sort=…&saved=true
DECISION

Runtime routing

The decision panel reports decisions actually returned by the backend. There is no client-side approval list or action allowlist.

POST /api/decision/select
{
  "context": { "…": "…" }
}
SECURITY

Server-side configuration

Browser Use credentials, model credentials and radar credentials must remain in server environment configuration. Do not store secrets in browser storage or ship them in frontend JavaScript.
